# BOC Life Portal Inventory

This folder contains a public-safe backup of BOC Life proposal portal inventory metadata captured on 2026-05-11.

Included:

- `boc-life-portal-products-2026-05-11.json`: 34 products across 10 portal categories.
- `boc-life-portal-ui-widgets-2026-05-11.json`: per-product UI fields and dropdown options.
- `boc-life-portal-ui-summary-2026-05-11.json`: compact per-product field summary.
- `BOC-Life-Proposal-Portal-Inventory-2026-05-11.xlsx`: workbook backup with summary, products, UI fields, and options sheets.

The repo copy excludes Safari cookies, proposal identifiers, browser-only session identifiers, and credentials. The data is product/UI metadata only; it is not a premium or surrender-value comparison matrix.
